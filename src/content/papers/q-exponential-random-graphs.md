abstract: "We introduce q-Exponential Random Graphs, a generalization of classical ERGs in which simple constraints can induce dependencies between edges. Unlike standard Shannon-based models, these ensembles can generate higher-order phenomena such as phase transitions, assortativity, and especially the coexistence of sparsity with clustering—a key feature of real-world networks. This provides a new framework for studying how correlations and dependencies shape complex network structure."
